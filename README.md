# Arrival Info App

Real-time bus arrival information display for Helsinki public transportation (HSL).

## Quick Start

```bash
npm install
npm run dev
```

Then open: **http://localhost:3000**

## Features

- 🚌 Real-time bus arrivals
- ⏰ Live clock (updates every second)
- 🟢 Green indicator for on-time buses
- 🔴 Red indicator for delayed buses
- ⏱️ Waiting time calculations
- 📱 Responsive design
